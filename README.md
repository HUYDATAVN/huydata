# huydata.vn

Website của HuyData: phần mềm và hỗ trợ sổ sách cho hộ kinh doanh, doanh nghiệp nhỏ.

- **Bản đang chạy:** v9, trang tĩnh (HTML dựng sẵn), đăng bằng GitHub Pages với tên miền `huydata.vn`.
- **Nội dung:** toàn bộ nằm trong `noi-dung.json`. Các trang HTML được sinh ra từ file này.
- **Quản trị:** `huydata.vn/quan-tri/` (cần PIN). Viết bài, sửa trang, đổi giá rồi bấm **Đăng lên GitHub**.
- **Đừng xóa:** `CNAME`, `.nojekyll`.

Hướng dẫn kỹ thuật cho người bảo trì: xem `CLAUDE.md`.
Bản cũ trước v9: nhánh `sao-luu-v8-truoc-v9`.
